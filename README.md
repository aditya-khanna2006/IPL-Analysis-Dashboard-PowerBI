# 🏏 IPL Analysis Dashboard (2008–2025)

An interactive **Power BI** dashboard that provides comprehensive insights into the Indian Premier League (IPL) from **2008 to 2025**. This project transforms raw IPL data into meaningful visualizations, enabling users to explore team performance, player achievements, and tournament statistics through an intuitive and dynamic interface.

---

## 📖 Project Overview

The IPL Analysis Dashboard is designed to deliver season-wise insights into one of the world's most popular T20 cricket leagues. By leveraging Power BI's data modeling and visualization capabilities, the dashboard presents key tournament metrics in a clean and interactive format.

Users can analyze individual IPL seasons using dynamic filters and instantly view updated statistics, team standings, award winners, and performance indicators.

## 📁 Dataset

The dashboard is built using four CSV datasets:

- `ipl_matches_data.csv`
- `ball_by_ball_data.csv`
- `players_data.csv`
- `teams_data.csv`

These datasets were transformed, modeled, and analyzed using Power Query and DAX before being integrated into the final dashboard.
